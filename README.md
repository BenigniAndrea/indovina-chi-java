# Indovina Chi Multiplayer in Java

Una trasposizione digitale del classico gioco da tavolo "Indovina Chi", sviluppata in Java con interfaccia grafica e supporto per il multiplayer in rete.

Oltre a mettere in pratica i concetti fondamentali della Programmazione Orientata agli Oggetti (OOP) per la gestione del database dei personaggi e della logica di esclusione, il progetto implementa un'architettura di rete. L'utilizzo dei Socket (Client-Server) permette infatti a due giocatori di connettersi e sfidarsi in tempo reale da due computer fisicamente separati.

**Tecnologie e concetti applicati:**
- Java 
- Networking (Socket Programming TCP/IP)
- Object-Oriented Programming (OOP)
